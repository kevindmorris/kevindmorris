## 🗂️ Resources that helped me

#### Git
- **[Learn Git Branching](https://learngitbranching.js.org/?locale=en_US)** - An interactive git visualization and tutorial. Aspiring students of git can use this app to educate and challenge themselves towards mastery of git!
- [Atlassian Git Tutorials](https://www.atlassian.com/git) - Review git commands and concepts!

#### Linux
- **[Linux Journey](https://linuxjourney.com/)** - Learn Linux with Free Linux Tutorial & Course

#### JavaScript
- **[Code Combat](https://codecombat.com/)** - This game teaches programming concepts, including JavaScript, within an RPG-style environment where players control a character by writing code.

#### CSS
- **[Froggy Flexbox](https://flexboxfroggy.com/)** - A game for learning CSS flexbox 🐸.
- **[CSS Diner](https://flukeout.github.io/)** - CSS Diner is an interactive online game designed to teach and practice CSS selectors.

#### SQL
- **[The SQL Murder Mystery](https://mystery.knightlab.com/)** - There's been a Murder in SQL City! The SQL Murder Mystery is designed to be both a self-directed lesson to learn SQL concepts and commands and a fun game for experienced SQL users to solve an intriguing crime.
- **[Lost at SQL](https://lost-at-sql.therobinlord.com/)** - A SQL learning game to help you pick up basic SQL skills - so that you can use queries to get information.
- **[SQLPD](https://sqlpd.com/)** - SQL Police Department is an online game where you solve crimes using SQL (and learn SQL in the process).
- **[SQL Noir](https://www.sqlnoir.com/)** - This open-source detective game expands on the crime-solving theme, presenting various cases that require SQL queries to uncover information and solve mysteries.
- **[SQL Squid Game](https://datalemur.com/sql-game)** - Inspired by the popular Netflix series, this game challenges users to write SQL queries to analyze player performance metrics and identify rogue elements within a fictional "Squid Game" organization.
